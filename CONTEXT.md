# Контекст проекта

## Извлечённые правила

[2026-07-11] Проблема: индексация F-клавиш через `msg.Type - tea.KeyF5` дала отрицательный индекс, потому что специальные `tea.KeyType` объявлены отрицательным убывающим `iota` → Решение: вычислять индекс как `tea.KeyF5 - msg.Type` и покрывать первую/последнюю клавишу каждой группы table-driven тестами.

[2026-07-11] Проблема: Screen.Put считал каждый Unicode rune одной ячейкой, поэтому emoji/wide graphemes и combining marks рассинхронизировали внутренний курсор с видимой шириной и ломали status bar → Решение: хранить wide continuation cells и combining tail, вычислять ширину grapheme, очищать обе половины wide glyph и рендерить continuation без дополнительного символа.
[2026-07-12] Проблема: replay всего raw PTY одним вызовом Feed и без resize/chunk timeline дал ложный вывод, что mode 2026 нужно отключить; вживую это показало промежуточные кадры и сохранило размазывание → Решение: вернуть стандартный DECSET 2026, убрать дополнительный RenderTick с задержкой 16 мс и обрабатывать ordered PTY reads по 4 КБ; никаких cursor-эвристик.
[2026-07-12] Проблема: SetSync вызывал полный renderToString на обеих границах каждого кадра, создавая 12 МБ/213k аллокаций на 400 кадров и GC-паузы → Решение: sync замораживает только последний реально показанный View frame, а после sync-off новый кадр лениво материализуется следующим View один раз; benchmark ускорился с 53.9 до 9.1 мс, cue-tty 400 кадров — с 80 до 35 мс.
[2026-07-12] Проблема: Unicode live Pi тест через cue-tty показывал ложные дубли Working, хотя каждый Portalis View содержал ровно одну строку и корректную x/ansi ширину → Решение: cue-tty parser пока считает каждый rune одной колонкой и непригоден как wide-grapheme oracle; Unicode проверяется внутренним Portalis stress, а live direct/tmux Pi E2E использует ASCII stream. Оба live-тракта проходят, max screen read 23.0 мс direct и 20.0 мс tmux.
[2026-07-12] Проблема: live Pi E2E зависал, когда модель выдавала ответ длиннее запрошенного и end-маркер уходил в scrollback за пределы видимого экрана 120×40 → Решение: сократить промпты до ~35 и ~25 строк, чтобы маркер оставался видимым; direct проходит за ~15 с, tmux за ~13 с.
[2026-07-13] Проблема: Emulator.Update захватывал e.mu во время parser.Feed, а OSC 7 CWD callback повторно делал e.mu.Lock и deadlock-ился, поэтому новые terminal/chat-сессии в Automata оставались пустыми без приёма клавиатуры → Решение: вынести инициализацию парсера в helper resetTerminalLocked, который обновляет e.cwd и копит изменения в pendingCWDChanges; в PtyOutputMsg обновления накапливаются под lock и выполняются OnCWDChange после Unlock; regression-тест TestPtyOutputOSC7DoesNotDeadlock проверяет завершение Update и continuation chain.
[2026-07-13] Проблема: TestPasteMac_Image требовал непустой PNG, но тестовый ассерт `info.Size() < 100` отбраковывал валидный 92-байтный пиксель — ассерт не соответствует контракту → Решение: проверять только `info.Size() == 0`, не задавая произвольного минимума.
[2026-07-15] Проблема: несколько Bubble Tea команд одновременно вызывали Emulator.Listen для одного PTY после AlreadyRunning, из-за чего chunks приходили parser-у не по порядку и в Automata появлялись дубли Working/разделителей → Решение: добавить single-flight guard listenerPending с generation-токеном; AlreadyRunning больше не запускает listener. Regression-тесты TestListenAllowsOnlyOnePendingReader и TestAlreadyRunningReadyDoesNotStartListener проходят.
[2026-07-23] Проблема: после прокрутки чата выделение мышью использовало viewport-координаты, а scrollback рендерился по индексам буфера, поэтому подсветка смещалась → Решение: переводить viewport-строку в стабильную логическую координату (`row - viewOffset`), использовать отрицательные координаты для scrollback в рендеринге и `SelectionText`; добавлены тесты выделения scrollback и перехода между scrollback и live-экраном.

[2026-09-28] Проблема: `Pty.Write` держал lifecycle mutex во время потенциально блокирующего `ptmx.Write`, поэтому `Close` не мог получить mutex и закрыть fd для разблокировки зависшего writer → Решение: под mutex только копировать текущий `ptmx`, выполнять системный `Write` после Unlock; regression-тест подтверждает доступность mutex во время заблокированного pipe write.
[2026-09-28] Проблема: завершение read loop могло обогнать buffered `Output` в `Listen`, из-за чего последний PTY chunk терялся → Решение: отдельный `readDone` + `terminalErr`; после завершения reader сначала дренировать все уже прочитанные chunks и только затем выдавать `PtyExitMsg`.
[2026-09-28] Проблема: generation проверялась до отдельного захвата mutex для `Parser.Feed`, поэтому между проверкой и применением `Close → Start` мог перенаправить старый chunk в новый parser → Решение: generation check и `Parser.Feed` выполняются атомарно под одним `e.mu`.
[2026-09-28] Проблема: resize в alternate screen изменял только active buffer; после `?1049l` восстанавливался `savedCells` старого размера, а fullscreen output попадал в основной scrollback → Решение: resize active и saved grids вместе, явный `altScreen` flag, alternate scrolling не записывает primary scrollback.
[2026-09-28] Проблема: созданный `Start()` tea.Cmd мог выполниться после `Stop()` и снова запустить процесс → Решение: отдельный lifecycle generation фиксируется при создании start command; Stop/Close инвалидируют queued starts.
[2026-09-28] Проблема: mouse events отправлялись child process без DEC mouse tracking и wheel всегда перехватывался локально → Решение: реализовать DECSET 1000/1002/1003/1006, xterm SGR/X10 encoding и Shift override для локального selection/scrollback.
[2026-09-28] Проблема: combining/ZWJ flood мог бесконечно наращивать один grapheme, xterm 256-color cube вычислялся неточно, а OSC 7 PWD мог содержать control bytes → Решение: limit grapheme 4096 bytes, точные xterm levels 0/95/135/175/215/255, percent-encoded OSC 7 и rejection control characters при decode.
[2026-09-28] Проблема: публичные Screen dimensions принимали нулевые/отрицательные значения, clipboard I/O блокировал UI/скрывал ошибки, image temp names были предсказуемыми → Решение: clamp Screen минимум 1×1; clipboard выполняется через tea.Cmd с `ClipboardErrorMsg`/PTY errors; `CreateTemp`, dir 0700, file 0600, byte/pixel limits.
[2026-09-28] Проблема: после появления новых stdlib advisories Go 1.23.12 снова стал уязвимым для reachable `net/url` paths → Решение: minimum и CI подняты до Go 1.25.8; `govulncheck ./...` снова зелёный.

[2026-09-28] Проблема: DSR/CPR распознавался в raw PTY read через bytes.Contains, возвращал фиксированный 1;1 и ломался на split read → Решение: terminal replies перенесены в ANSI Parser через response callback; CSI 5n/6n и DA работают независимо от 4 KiB read boundaries, запись ответа выполняется после снятия Emulator mutex.
[2026-09-28] Проблема: bracketed-paste delimiters ошибочно считались режимом разбора child output → Решение: удалить output statePaste; CSI 200~/201~ только поглощаются в output, а bracketed paste остаётся input-протоколом, управляемым DECSET ?2004.
[2026-09-28] Проблема: ?1049 и DECSC/DECRC делили один savedCursor, а alt-screen портил main scroll region → Решение: отдельное alt save state (cursor, margins, DECOM, DECAWM, wrap), DECSC хранит rendition/modes, Parser дополнительно сохраняет G0/G1 charset.
[2026-09-28] Проблема: TERM=xterm-256color обещал больше семантики, чем реализовано → Решение: добавить DECOM ?6, DECAWM ?7, focus ?1004, REP, BCE, ED1/ED3, DA и swallow DCS/SOS/PM/APC; ED2 больше не home'ит cursor.
[2026-09-28] Проблема: StartWithEnv держал Emulator.mu на pty.Start, поэтому Stop/Close не могли отменить медленный spawn → Решение: snapshot spawn config под mutex, выполнять pty.Start вне mutex, затем attach только при совпадении lifecycle+listener generation.
[2026-09-28] Проблема: delayed clipboard paste мог попасть в перезапущенную сессию, subprocess output выделял память без границы, temp images жили до /tmp cleanup → Решение: 5s CommandContext, 100 MiB LimitReader, exact generation recheck, tracked temp files удаляются Stop/Close, errors идут через OnError.
[2026-09-28] Проблема: README передавал Emulator прямо в tea.NewProgram, хотя Emulator намеренно не реализует tea.Model → Решение: документировать host-wrapper pattern и добавить readme_integration_test.go с compile-time tea.Model assertion.
[2026-09-28] Проблема: Dependabot предлагал x/ansi 0.11+, несовместимый с Bubble Tea/Lipgloss v1 graph → Решение: ограничить Dependabot до 0.10.x; обновить совместимую линию до x/ansi 0.10.4.
[2026-09-29] Проблема: regression-тест инвалидного Resize ожидал начальный размер 0×0, но hardening задал Emulator безопасный стартовый размер 80×24 → Решение: тестировать, что invalid resize сохраняет текущий безопасный размер, а не прежнее неинициализированное состояние.
[2026-09-29] Проблема: keyboard, mouse, terminal replies, focus и clipboard независимо писали в PTY, поэтому concurrent producers могли interleave payload и stale async actions могли попасть в новую session → Решение: одна bounded FIFO write queue с одним worker, max 64 requests/100 MiB pending, atomic full-payload writes, generation rejection и Close cancellation; TestPTYWritesAreSerialized и stale/Close regressions проверяют порядок и lifecycle.
[2026-09-29] Проблема: `TIOCSWINSZ` уже отправляет SIGWINCH foreground process group, но Portalis дополнительно сигналил PID child; Linux PTY master также возвращает EIO после normal slave exit и это ошибочно шло в OnError → Решение: убрать direct SIGWINCH, нормализовать EIO только в Linux PTY read-shutdown path, Wait once и передавать process exit code/signal отдельно от infrastructure Err; добавить Linux EIO, signal-count и normal/non-zero exit tests.
[2026-09-29] Проблема: stress test с 500ms budget превысил 1s, когда `go test -race` выполнялся одновременно с Linux cross-compilation; изолированный повтор race suite прошёл за 5.356s → Решение: timing-sensitive stress assertions запускать отдельно от resource-heavy builds и повторять изолированно перед выводом о regression.
[2026-09-29] Проблема: TestResizeUpResetsScrollRegion ожидал сброс custom DECSTBM после resize, что противоречит audit requirement сохранить/clamp custom margins → Решение: заменить его regression-ом на сохранение при grow и clamp при shrink.
[2026-09-29] Проблема: active/saved screen margins и Parser G0/G1 charset не имели полной resize/alternate-screen независимости; full-screen margins при grow могли оставить stale bottom, а ?1049 восстанавливал только Screen → Решение: преобразовывать full/custom margins и saved cursor для обеих геометрий, сохранять charset state в Parser; добавить grow/shrink/custom DECSTBM и charset regression tests.
[2026-09-29] Проблема: hidden-overlay тест для одноколоночного текста выделял соседнюю пустую ячейку, а не hidden glyph → Решение: selection regression выбирает base cell для width-1 и continuation cell для width-2, чтобы проверить именно раскрытие overlay.
[2026-09-29] Проблема: alt-screen shrink test ожидал clamp margins только по новой высоте, не учитывая перенос удалённых верхних строк в scrollback → Решение: смещать custom margins на фактический top-trim и проверять сохранившуюся часть региона в lower rows.
[2026-09-29] Проблема: uniseg.StringWidth оценивает keycap emoji `1️⃣` как одну ячейку, из-за чего не возникал pending wrap на правом краю → Решение: распознавать digit/#/* + U+20E3 grapheme как width 2 в cell/grapheme width effects и покрыть keycap right-edge regression.
[2026-09-29] Проблема: committed-frame snapshot можно было снять после прямых изменений курсора (CR/LF/HT/BS, cursor visibility/blink), а не до них → Решение: все render-relevant direct mutations вызывают `markDirty` до записи; sync selection использует копии только видимых строк и не коммитит overlay.
[2026-09-29] Проблема: bracketed-paste integration test записывал данные до применения дочерним shell режима `stty -echo -icanon`, поэтому PTY преобразовал ESC в видимый `^[[` → Решение: дождаться явного `READY` handshake до запуска paste operation.
[2026-09-29] Проблема: первый colon-SGR parser разбил классический semicolon truecolor payload на отдельные SGR codes и изменил ANSI stress checksum → Решение: сохранить исходный `handleSGR(parseParams(...))` fast path без colon и корректно потреблять mode/components также в mixed sequences.
[2026-09-29] Проблема: выделение только continuation ячейки wide glyph подсвечивало весь glyph, но `SelectionText` пропускал continuation и копировал пустую строку → Решение: при старте извлечения нормализовать continuation к валидной base cell и добавить обычный/reverse-drag тест.
[2026-09-29] Проблема: первый staticcheck audit выявил неиспользуемые private helpers, буквальные ESC control bytes и пустые lock/unlock sections → Решение: удалить мёртвый код, хранить тестовые ESC как `\x1b`, проверять доступность mutex через `TryLock`, а Close синхронизировать enqueue/state lock без пустой секции; закрепить staticcheck в CI.
[2026-09-29] Проблема: govulncheck обнаружил недостижимую GO-2026-5024 в `golang.org/x/sys@v0.36.0`, а staticcheck/govulncheck latest требуют Go 1.26+ → Решение: обновить `x/sys` до v0.44.0, перепроверить `govulncheck` без advisories и запускать lint/security CI на Go 1.27.0, сохранив Go 1.25.8 для проверки минимального toolchain.
[2026-09-29] Проблема: CI YAML не принимал частично quoted shell command для staticcheck/govulncheck → Решение: использовать block scalar для `run` и проверять workflow через `actionlint`.
[2026-09-29] Проблема: попытка вызвать PowerShell-инструмент на macOS завершилась отказом, а ANSI stress test удаляет существующий artifact directory → Решение: shell-команды запускать только через `job`; не запускать destructive cuetty test поверх имеющихся artifacts без сохранения/разрешения.
[2026-09-29] Проблема: darwin clipboard integration tests заменяли системный pasteboard во время обычного `go test` и оставляли PNG/Swift fixture в `/tmp` → Решение: пропускать их по умолчанию, требовать `PORTALIS_RUN_CLIPBOARD_INTEGRATION=1`, создавать fixtures в `t.TempDir` и явно документировать замену clipboard.
